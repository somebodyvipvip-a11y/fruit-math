# 10以内加减法 · 水果练习生成器

一个给孩子练口算的网页小工具。打开即用，随机出题，可直接打印成纸质练习纸。

**在线使用：** https://somebodyvipvip-a11y.github.io/fruit-math/

单文件、零依赖、无构建，把 `index.html` 下载下来双击就能用，断网也能跑。

## 功能

- **题型切换**：仅加法 / 仅减法 / 混合
  - 加法：两个加数之和不超过 10
  - 减法：结果不小于 0（不会出现负数）
- **水果图示**：每道题配一组水果 emoji，按一行 5 个排列，孩子可以先数一数再算
  - 加法：两组水果中间一个 `+`
  - 减法：被减掉的水果上打一道红色斜杠，直观看出"拿走几个"
- **换一批题目**：一键重新随机生成全部题目
- **打印**：A5 竖版，每页 12 道题、分两列排布，跨页自动分页，打印时工具栏自动隐藏
- **显示答案**：勾选后答案直接填在虚线框里，方便家长批改
- **页数**：可选 1–50 页，一次生成多页

## 使用方法

1. 打开在线地址，或本地双击 `index.html`
2. 选择题型、填页数，点「换一批题目」直到满意
3. 点「打印」，在打印设置里把纸张选成 **A5**，边距选「无」或「默认」，并勾选「背景图形」以保留卡片配色
4. 需要答案版，就勾上「显示答案」再打印一份

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，样式和脚本全部内联在 `index.html` 里；无外部依赖、无 CDN、无字体外链
- 水果用 emoji 实现，10 种水果搭配 5 套边框配色循环使用，相邻题目不易混淆
- 页面尺寸按 A5（148mm × 210mm）设计，打印时由 `@page { size: A5 portrait; margin: 0 }` 控制
- 常用改动位置：
  - 每页题目数量：`buildPage()` 里的循环次数 `idx < 12`
  - 每页列数：CSS 中 `.cols` 的 `grid-template-columns`
  - 水果种类：脚本顶部的 `FRUITS` 数组

